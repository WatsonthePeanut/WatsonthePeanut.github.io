Linux Installation Record

发表于2026-01-11
|总字数:922|阅读时长:2分钟|浏览量:

前言

受够了 Windows 动不动就强制更新还一堆广告，技术群的群 u 们也都在用 Linux。想着以后工作了或多或少都得接触 GNU/Linux，也希望在群 u 们吹水时也能有点参与感， 索性趁现在现在有时间就折腾折腾。在观看了 unixchad 的视频 后大受震撼，心血来潮从某鱼上购入了一台二手 ThinkPad T14s Gen1 AMD 版本。

在翻阅了网上一堆教程之后，GNU/Linux 我选择从 Linux Mint 开始入门，熟悉了之后再尝试 Arch Linux。本文旨在记录 Linux 的折腾过程，装坏了还可以回头看看怎么个事。

准备工作

制作系统盘

下载 ISO 文件

到目标系统的官网下载 ISO 文件，我下载的是 Linux Mint 22.2 Cinnamon Edition。下载结束后可以在文件目录中使用:

命令校验输出的哈希值与官网给出的 sha256sum.txt 中的哈希值一致。如不一致则需要重新下载。

安装 Rufus

安装 Rufus 用于制作系统盘。接着准备一个 U 盘，Rufus 将会格式化 U 盘，所以如果 U 盘内有文件务必进行备份！ 插入 U 盘，双击运行 rufus，设备选择 目标 U 盘，引导类型选择 下载好的镜像文件，分区类型 如果电脑用的是 UEFI 则选择 GPT，如果是 BIOS 则选择 MBR，剩下的保持默认即可。点击开始，写入完成后系统盘制作完成。

准备目标电脑

由于我只安装 Linux，不保留 Windows 系统，所以我没有进行硬盘分区、关闭 Windows 快速启动、关闭 Windows BitLocker 等等工作。如果有安装双系统的需求，请参考其它教程。

进入 UEFI

将制作好的系统盘插入要安装 Linux 的电脑中，并将电脑关机。启动计算机，我的 ThinkPad T14s 在显示 ThinkPad 徽标时，按 F1 以进入 UEFI。

关闭安全启动。

将系统盘设置成启动项的第一个。

保存并退出，启动第一项即可，这样我们就进入了 live 环境。此时我们只是从 U 盘加载 Linux，还没有将 Linux 系统写入硬盘。

将 Linux 写入硬盘

在 live 环境先检查好：Wi-Fi 能不能连接、键盘/触控板是否正常、屏幕分辨率是否正常、声音是否正常输出等，接着双击 Install Linux Mint 图标，按照安装器的引导进行安装即可。最关键的一步是选择 安装类型，我不安装双系统，所以选择 清除整个磁盘并安装 Linux Mint。

接着耐心等待安装完成并重启即可。

Hello, Linux!

初始配置

进入 Linux Mint 后的第一件事是更新系统到最新状态。点击第一步，打开更新管理器，更换一个速度最快的镜像源并点击更新 APT 缓存，接着点击应用更新，安装所有的更新。安装完成后重启系统，打开驱动管理器，检查是否需要额外安装驱动。接着打开系统设置点击输入法，安装语言支持包，完成后将输入法框架改为 Fcitx，再次重启后驱动和输入法就生效了。

软件安装

进入软件管理器，首选项 -> 显示未经验证的 Flatpak 软件，现在 Linux Mint 就配置好了！安装软件时既可以从软件管理器安装，也可以通过官方提供的 .deb 包安装。
